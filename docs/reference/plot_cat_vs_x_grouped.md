# Plot Clustered Longitudinal (Panel) Data

Functions that work with longitudinal data and plot the outcomes vs a
covariate with respect to some grouping, e.g. clustering found by
[`clustGLMM`](https://vavrajan.github.io/clustGLMM/reference/clustGLMM.md).

## Usage

``` r
plot_num_vs_x_grouped(data, y = "y", x = "x", group, id = "i", units, 
                      xbreaks, add_lowess = TRUE, alpha = 0.7,
                      legend_placement = "topright")
plot_cat_vs_x_grouped(data, y = "y", x = "x", group, 
                      xbreaks, main = NA, margin = 0.05, reverse = FALSE)
```

## Arguments

- data:

  a `data.frame` containing `y`, `x`, `group`, `id`.

- y:

  a name of the outcome to be plotted.

- x:

  a name of numeric or factor regressor.

- group:

  a name of the clustering variable that divides different ids into
  groups. If missing, all observations are given the label "0" plotted
  with
  [`slategray.colors`](https://vavrajan.github.io/clustGLMM/reference/slategray.colors.md)
  and `legend_placement` is set by default to `NULL`.

- id:

  a name of the id variable.

- units:

  a vector of unit ids to be plotted, if missing all ids are plotted.

- xbreaks:

  a set of breaks along which to cut regressor `x`, if missing `x` is
  divided equidistantly into 10 categories.

- add_lowess:

  a Boolean whether to add lowess curves for each group label.

- alpha:

  a color transparency factor; applied only for overlapping boxplots if
  covariate `x` is `factor`.

- main:

  plot title to be printed above the plot.

- margin:

  how far from each other should different groups be displayed.

- reverse:

  a Boolean whether to reverse the order of ordinal categories; if
  `TRUE` 0 on top, if `FALSE` 0 at the bottom.

- legend_placement:

  a string describing the position of legend (see
  [`legend`](https://rdrr.io/r/graphics/legend.html)) or `NULL` to omit
  the legend.

## Details

Colors are created automatically by `rainbow_hcl` from package
`colorspace`.
[`slategray.colors`](https://vavrajan.github.io/clustGLMM/reference/slategray.colors.md)
are used for group 0 (unclassified).

Output of `plot_num_vs_x_grouped` depends on the type of covariate `x`:

- factor:

  boxplots of the outcome `y` wrt levels of covariate `x` with a
  transparent color determined by `group`. Boxplots for the same group
  may overlap, hence, transparent colors.

- numeric:

  spaghetti-plots the outcome `y` wrt covariate `x` colored by `group`.
  Only units included in `units` are plotted.

If `x` is not already a factor, `plot_cat_vs_x_grouped` divides the data
by a numeric covariate `x` into groups divided by `xbreaks`. Then, for
each group label in `group` (including group 0 = unclassified) a
spineplot capturing the evolution of proportions of a categorical
outcome `y` wrt the covariate `x`.

## Value

The functions do not return anything but produce a plot.

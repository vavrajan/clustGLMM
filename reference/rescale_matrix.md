# Rescale the Raw Draws

In
[`clustGLMM`](https://vavrajan.github.io/clustGLMM/reference/clustGLMM.md)
if `standardize=TRUE`, the model parameters are sampled using the scaled
numeric outcomes and regressors. The goal of these functions is to
transform these parameters into the original scale. Works for a specific
chain only.

## Usage

``` r
rescale_matrix(draws, settings, family, lfixnames, lgrpnames, lrannames, 
               Kord, Kcat, centers, scales)
rescale_list(draws, settings, family, lfixnames, lgrpnames, lrannames, 
             Kord, Kcat, centers, scales)
```

## Arguments

- draws:

  an element of `clustGLMM$draws` for a certain chain, either a list or
  a matrix.

- settings:

  a matrix containing the information about model parameters.

- family:

  a vector of distributional families named by the outcome name in
  `data`.

- lfixnames:

  a list of `fixed` regressors for each outcome.

- lgrpnames:

  a list of `group` regressors for each outcome.

- lrannames:

  a list of `random` regressors for each outcome.

- Kord:

  a named vector of number of levels (minus 1) for ordinal outcomes.

- Kcat:

  a named vector of number of levels (minus 1) for categorical outcomes.

- centers:

  a named vector of centers of numeric outcomes and regressors.

- scales:

  a named vector of scales of numeric outcomes and regressors.

## Details

Regression coefficients are divided by the corresponding scale from
`scales`, except intercept parameters. These are shifted by
corresponding linear combination of `centers` given by rescaled other
coefficients. Parameters for numeric outcomes also have to account for
the rescaling of the outcome variable. For ordinal outcomes, intercepts
are not included among the regressors, this is carried by the ordered
intercepts `c_ord` and its reparametrizations. Also random effects
including the covariance matrix (and related parameters) are rescaled.
More details in the paper.

## Value

Returns an object equivalent to `draws`.

# Plot the Output of `clustGLMM`

Triggers plotting functions for selected parameter depending on the
choice of the plot.

## Usage

``` r
# S3 method for class 'clustglmm'
plot(x, what="ng", which="traceplots", ng_trace_chain_split=TRUE, ...)
```

## Arguments

- x:

  an object of class `"clustglmm"`, an output of function `clustGLMM`.

- what:

  a string containing the name of the parameter.

- which:

  a string declaring the type of the plot to be created.

- ng_trace_chain_split:

  a logical indicating whether cluster occupancy numbers `ng` of all
  clusters should be plotted together in one plot separately for each
  chain (`TRUE`), or separate plots comparing different chains for each
  cluster (`FALSE`).

- ...:

  other arguments.

## Details

Depending on `which` the following functions are called:

- ACF:

  creates auto-correlation function plot, calls
  [`plot_ACF`](https://vavrajan.github.io/clustGLMM/reference/plot_diagnostics.md)
  or
  [`plot_ACF_param`](https://vavrajan.github.io/clustGLMM/reference/plot_diagnostics.md).

- ECDF:

  creates empirical cumulative distribution function plot, calls
  [`plot_ECDF`](https://vavrajan.github.io/clustGLMM/reference/plot_diagnostics.md)
  or
  [`plot_ECDF_param`](https://vavrajan.github.io/clustGLMM/reference/plot_diagnostics.md).

- kerneldensity:

  creates kernel density estimator plot, calls
  [`plot_kerneldensity`](https://vavrajan.github.io/clustGLMM/reference/plot_diagnostics.md)
  or
  [`plot_kerneldensity_param`](https://vavrajan.github.io/clustGLMM/reference/plot_diagnostics.md).

- traceplots:

  creates traceplots (samples vs iteration), calls
  [`plot_traceplots`](https://vavrajan.github.io/clustGLMM/reference/plot_diagnostics.md)
  or
  [`plot_traceplots_param`](https://vavrajan.github.io/clustGLMM/reference/plot_diagnostics.md).

- clusters_ECDF:

  creates empirical cumulative distribution function plot where
  different clusters are compared (`what` needs to be a cluster-specific
  parameter), calls
  [`plot_clusters`](https://vavrajan.github.io/clustGLMM/reference/plot_diagnostics.md)
  or
  [`plot_clusters_ECDF_param`](https://vavrajan.github.io/clustGLMM/reference/plot_diagnostics.md).

- clusters_kerneldensity:

  creates kernel density estimator plot where different clusters are
  compared (`what` needs to be a cluster-specific parameter), calls
  [`plot_clusters`](https://vavrajan.github.io/clustGLMM/reference/plot_diagnostics.md)
  or
  [`plot_clusters_kerneldensity_param`](https://vavrajan.github.io/clustGLMM/reference/plot_diagnostics.md).

If the user tries to specify one of: `gspec` or `dimspec`, it is treated
as an attempt to plot only a single scalar parameter (functions without
`..._param`). Be careful to specify the dimensions appropriately
(including `yspec`). Inner function
[`get_scalar_samples`](https://vavrajan.github.io/clustGLMM/reference/get_scalar_samples.md)
triggers a warning or even an error if misspecified.

Otherwise if neither `gspec` nor `dimspec` are given, then `..._param`
function is triggered. It is designed to create plots for all chains and
all dimensions related to the given `what` model parameter. The output
is organized into multiple carefully arranged layout. The only way to
plot a smaller subset of parameters is via `yspec` argument, which
accepts even multiple outcome values. However, only plots for an
intersection of given and plausible outcomes for the given parameter are
returned.

These functions except also `burnin` (initial part of the chain to be
ignored), `thin` (plot only every `thin`th sample) and `chains` (a
vector of chain numbers to be plotted).

## Value

No return value, only creates plots.
